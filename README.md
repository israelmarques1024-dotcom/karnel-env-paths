Display the active Karnel version and XDG-based config, data, cache, plugin,
and Termux prefix paths. This is useful when diagnosing an installation or
locating Karnel state without modifying it.

```bash
karnel plugin install karnel-env-paths
karnel karnel-env-paths
```
